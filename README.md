# Customer Sales Data Analysis

## Project Overview
Exploratory Data Analysis of customer sales data using
Python, Pandas, NumPy, Matplotlib, and Seaborn.

## Objectives
- Analyze customer purchasing patterns
- Identify sales trends across different states
- Analyze sales by gender and age group
- Visualize product-category performance

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
